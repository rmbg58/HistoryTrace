# 设计系统(古风)

> 改视觉令牌、主组件体系或页面风格前必读。长期规则变化须追加 ADR;具体实现位置同时登记到 02-CONVENTIONS.md。
> 意象基调:**宣纸为底,墨色为骨,朱砂点睛**——古籍版式 + 文人地图(青绿设色)+ 金石印章的现代演绎。

## 风格目标

1. **古雅克制**:低饱和、大留白、层次靠墨色浓淡而非边框阴影;像一页摊开的志书,不像后台面板
2. **纸墨质感**:背景宣纸米色微晕染,边界如墨线勾勒,政区填充如青绿山水淡彩
3. **学术可信融入视觉**:置信度用"印章/批注"隐喻(G4 朱印、存疑者淡墨旁批),溯源抽屉做成"夹页/笺注"样式
4. **文字为主角**:楷/宋字体栈,引文排版遵循古籍行款(繁体原字不转换),tabular 数字对齐年份
5. **动效如墨**:淡入晕染 150–250ms,无弹跳无拟物翻转;尊重 prefers-reduced-motion

## 设计令牌

> 事实源:`web/src/styles/tokens.css`(脚手架后建立);下表为规范值。

| 类别 | 令牌(示意名) | 规范 |
|------|-------------|------|
| 颜色—纸 | `--paper`(宣纸底 #f6f1e3)、`--paper-aged`(陈纸 #efe6d0)、`--paper-deep`(深背景/夜览 #2e2a24 配浅墨字) | 全局底色;卡片用微深一档 + 纸纹(细噪点/纤维,SVG 实现,禁图片依赖) |
| 颜色—墨 | `--ink`(正墨 #2f2b26)、`--ink-strong`(题字 #1f1c18)、`--ink-soft`(正文 #4a443c)、`--ink-faint`(旁注 #8a8272) | 文字四级;正文对比度 ≥ AA(墨 #4a443c on 宣纸 #f6f1e3 ≈ 7.8:1) |
| 颜色—朱 | `--cinnabar`(朱砂 #9e3d34,印章/高亮/当前朝代)、`--cinnabar-soft`(淡朱,悬浮/选中底) | 点睛色,占比 <5%;禁大面积使用 |
| 颜色—辅助 | `--azurite`(石青,水系/东南政区)、`--malachite`(石绿,山地/西南)、`--ochre`(赭石,北方政区)、`--indigo`(黛蓝,链接) | 政区淡彩取青绿山水设色,饱和度低(填充透明度 8–18%),边界一律墨线 |
| 字体 | 标题 `"Kaiti SC","STKaiti","KaiTi","Noto Serif SC",serif`;正文/引文 `"Songti SC","STSong","SimSun","Noto Serif SC",serif`;数据/年份 `ui-monospace,"SF Mono",monospace`(tabular) | 系统字体栈起步(OT-002 评估自托管思源宋体/楷体 OFL);禁用无衬线做正文 |
| 间距与尺寸 | 4 的倍数;卡片内边距 ≥16;页面内容宽随地图满幅,面板固定 360–420 | 密度偏疏朗;控件高 ≥36(触控) |
| 圆角与阴影 | 圆角 0–4px(克制);阴影 = 纸叠层次(1–2px 实边 + 极淡投影),禁大弥散阴影 | 古籍无圆角大阴影;分隔用细墨线(1px `--ink-faint` 30%) |
| 动效 | `--motion-fast` 150ms / `--motion-med` 250ms;曲线 ease-out;地图切换淡入如墨晕 | 全部动效可被 prefers-reduced-motion 关闭 |
| 状态 | 加载:墨点/卷轴进度;空:留白 + 一行楷体小字;错误:淡朱边 + 说明;禁用:淡墨 | 状态文案与正文同体系,不引入第三方插画 |

### 置信度视觉(G 分级 → 古风隐喻)

| 等级 | 视觉 |
|------|------|
| G4 | 名称旁小朱印(印章形 SVG,内字"考") |
| G3 | 墨字 + 右上角"多源"小签 |
| G2 | 淡墨虚线 + 角标"单源",可展开异文 |
| G1 | 默认不渲染;检索可见时淡墨 + 旁批"存疑" |

## 组件分层

| 层级 | 所有权 | 允许变化 |
|------|--------|----------|
| 基础零件 | web/src/components/(自绘:印章 Badge、笺注 Panel、墨线 Divider、朝代 Chip) | 尽量不项目化修改 |
| 组合组件 | web/src/components/(时间轴 Timeline、沿革卡片 LineageCard、溯源抽屉 SourceDrawer) | 布局、状态、少量配置 |
| 页面区块 | web/src/sections/(地图舞台 MapStage、朝代带 DynastyBand、图例) | 品牌与页面组合 |
| 业务页面 | web/src/pages/(主视图 = 地图 + 三面板) | 项目专属 |

主组件体系:自绘(无第三方);禁止混入:任何 UI 组件库、第三方图标库。公共组件晋升走 `/devinit harvest`,不在页面任务中顺手建设。

## 地图样式专项

- 底图:矢量淡彩(非卫星),或宣纸色 raster + 细等高线;水系石青细线
- 历史疆界:墨线描边(1.5–2px)按朝代主线浓淡;相邻快照切换用"幽灵边界"(淡墨虚线)表达增损
- 政区填充:青绿设色系低透明度;**精度弱(BORDERPRECISION 低)的几何视觉再降一档 + 图例注明"示意"**
- 争议/异说:朱笔虚线;都城 = 印章图标;诗人行迹 = 淡金/赭色虚线渐显
- 地名标注:楷体,古今双注(古名墨、今名淡墨小字)

## 响应式与验收

- 断点:桌面优先(≥1280 完整三栏:地图 + 时间轴 + 沿革卡片);平板(≥768)面板抽屉化;移动(<768)地图全幅 + 底部抽屉
- 键盘/焦点:时间轴与面板可键盘操作,焦点环用朱砂细框;对比度 AA;prefers-reduced-motion 全局降级
- 核心页面与目标设备:主视图,桌面 Chrome/Safari + 移动 Safari
- 浏览器/设备/人工证据:待确认(脚手架后建立 screenshots/ 目录留存)
