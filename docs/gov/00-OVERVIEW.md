# 项目概览

## 目标

做"可信"的中国历史时空互动平台:从先秦至今按朝代/年份切换疆域与政区,点选任一地点查看历代名称沿革,叠加历史事件与诗人足迹+作品+时空线索,所有数据经多来源多轮次校验、可信度分级展示。

给谁用:历史爱好者、学生与教师、数字人文研究者和开源数据社区。成功标准(MVP):朝代切换顺滑(<100ms)、任一种子地点可看 ≥5 朝代名称且每条可溯源、核心图层 G3 以上占比 ≥90%(长期)。

差异化:既有产品要么数据不可再分发(jiangshan-map/CHGIS 派生)、要么封闭(搜韵编年地图)、要么无溯源(发现中国)。**本项目的护城河 = 自建的、声明式(attestation)的、经多轮校验的开放数据。**

## 技术底座

| 领域 | 选择 | 理由(可为"待定") |
|------|------|---------------------|
| 项目形态 | Web 应用(纯前端静态站)+ 数据管线 CLI | 无登录/无数据库需求;数据即代码;零运维 |
| 语言/运行时 | TypeScript(node 22)+ Python ≥3.12(uv) | 前端交互 + 数据 ETL/校验各用最适工具 |
| 框架与组件策略 | Vite + 原生 TS(无框架、无组件库),古风 UI 全自绘 | 参考 jiangshan-map 无框架路线;规避 GPL 传染与组件库默认风格干扰 |
| 地图与分发 | MapLibre GL JS + PMTiles(单文件静态瓦片) | 开源无 token;静态托管即可按需加载 |
| 数据库/外部服务 | 无数据库;ctext.org API(可选,低频点查) | claims 为 git 版本化 JSON,SQLite 仅作派生缓存 |
| 个人模板 | none(dev-kit 已关联,Bases 均为实验性 admin/user-web 壳,不匹配本项目,未采用) | 初始化基线,不是实时共享依赖 |
| 包管理 | pnpm(web)/ uv(pipelines) | 本机已装 pnpm 12、uv 0.12 |
| 测试框架 | vitest(web)/ pytest(pipelines) | 按栈默认 |

固定项:语言与包管理器、目录约定、验证命令、许可红线、校验协议铁律。可配置项:设计令牌(古风)、地图样式、数据模型扩展。项目专属项:校验流水线规则、地名沿革领域逻辑、朝代快照构建。

## 许可(已决定,ADR-002)

代码 MIT;自建数据(`data/`)CC BY-SA 4.0;发布产物只含白名单来源(WHG CC-BY / Cliopatria Apache-2.0 / 维基文库 CC-BY-SA / chinese-poetry MIT / GeoNames CC-BY)。CHGIS、CBDB 仅本地参照不入仓库;中华书局点校本只参校不转录;暂不走学术合作授权路线。

## 非目标(明确不做)

- 不做用户系统、UGC 在线编辑(复核走 git PR)
- 不做世界史(以中国历史疆域为范围)
- 不做商业变现;不使用任何不可分发数据源进入发布产物
- 不自建后端服务与数据库(MVP/P1 阶段)

## 术语表

| 术语 | 含义 |
|------|------|
| Claim / Attestation / Verdict | 声明(带来源断言)/ 佐证(来源+引文+certainty)/ 裁决(人工判断记录),见 verification-protocol §1 |
| L1–L5 / R0–R4 / G1–G4 | 校验五层(四校法+对齐)/ 五个轮次 / 置信四级,见 verification-protocol §3–5 |
| 沿革 | 某地点历代名称与隶属变迁序列 |
| 系年 | 给作品确定创作年代 |
| gazetteer | 地名录(地名→坐标+时期) |
| PMTiles | 单文件瓦片归档格式,支持静态托管按需加载 |
